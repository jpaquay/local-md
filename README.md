# Local Markdown Viewer (`local-md`)

A fast, interactive local Markdown viewer and presentation engine with real-time live preview, KaTeX math rendering, Mermaid diagramming, code highlighting, and WebSocket-backed filesystem synchronization.

## Features

- ⚡ **Vite + React 19 + TypeScript**: Modern, ultra-fast frontend build.
- 📐 **Rich Markdown & Math**: Built-in support for GitHub Flavored Markdown, KaTeX formulas, and Mermaid diagrams.
- 🎨 **Code Highlighting**: Syntax highlighting powered by `highlight.js`.
- 🐍 **Python Live Server**: Optional `server.py` backend providing live file streaming and directory browsing.

## Quickstart

### Prerequisites
- Node.js (v18+)
- Python 3.10+ (optional, for backend server)

### Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Or run the bundled launcher
./run.sh
```
